## Not written (and why)

- `Geocoding__ApiKey`: deploy.ps1 writes it unconditionally from the parameter default (a plaintext secret, not a Key
  Vault reference). Confirming the default is the value dev actually uses required reading a secret, which was denied
  by the session's permission guard. Left for the owner.
- Parameter-gated keys deploy.ps1 writes only when a parameter is passed (all defaults empty): `ClinketApi__InternalApiKey`,
  `Telnyx__*`, `TwoFactor__*`, `Mailchimp__*`, `Stripe__*`, `Razorpay__*`, `Payments__PromoEnabled`,
  `Payments__PromoSunset__*`, `Payments__TransferDelayHours`, `Payments__Booking__RefundRequestWindowHours`,
  `Payments__TierLimitAdminAlertsEnabled`, `Plivo__AuthId/AuthToken/ApplicationId/SignatureAuthTokens`. A dev run without
  those parameters writes nothing, so nothing is added.
- Orphans left in place (per instruction): `AISearch__ApiKey`, `AISearch__Endpoint`, `AISearch__IndexName`,
  `AISearch__KnowledgeIndexName`, `AISearch__ProviderIndexName`, `Invoice__DefaultCurrency`,
  `CosmosDb__ChangeFeed__EnablePerDocumentFailureTracking`, `AzureFunctionsJobHost__extensions__cosmosDB__feedPollDelay`,
  `...__leaseAcquireInterval`, `...__leaseRenewInterval` (the last four are removed by deploy.ps1 L7542 on its next run).

## Result

Applied 2026-10-02.

- **Queues**: `insights-day-rollup-dev` and `voice-number-operations-dev` were created in BOTH `clinket-servicebus-ca-nonprod`
  and `clinket-servicebus-in-nonprod`. Read back: lock PT5M, maxDelivery 5, sessions off, partitioning off, 1024 MB,
  DLQ-on-expiry on, batched on, express off, autoDeleteOnIdle max. insights: dup-detect on, window P1D, TTL P1D.
  voice-number-operations: dup-detect off, TTL PT1H. The read-back window of PT10M is the service default and does nothing while detection is off; events.json omits it.
  Both namespaces now hold all 47 entities that events.json defines (46 queues + 1 topic).

  A before/after name diff shows 0 pre-existing keys removed. All 14 values per app read back equal to the tables above
  (IN: INR, 2.50, 0, PLIVO, 0, `0 0 4 * * *`).
- **Verification**: `hostruntime/admin/host/status`, then `hostruntime/admin/functions/<name>/status` for every function
  that ARM `.../functions` lists. CA: host Running, no host errors, **90/90 clean**. IN: host Running, no host errors,
  **90/90 clean**. The six previously broken functions (TrialReminders, VoiceNumberLifecycle, ProviderScoreSafetyNet,
