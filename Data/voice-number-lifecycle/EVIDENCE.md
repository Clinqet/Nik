## Findings that matter before automation

| Priority | Verified observation | Required design response |
|---|---|---|
| P0 | Missing/unparseable carrier prices become zero and may pass the monthly ceiling | Explicit unknown price; no purchase. Reject negative/nonfinite/overflow amounts, unsupported currencies and unsafe sub-cent rounding |
| P0 | General SaveApplicationAsync accepts changed target in dedicated mode; only active own-number mode has the special change guard | Server-enforced admin-only replacement; verified initial target cannot be inferred from read-only UI |
| P0 | EvaluateBinding reads then later SyncVoicelineFromApplicationAsync overwrites BusinessId. Its ETag retry reapplies the same proposed owner without rerunning binding evaluation | Shared atomic inventory claim and generation-fenced projection; test two businesses racing an owned DID |
| P0 | Existing carrier purchase has no durable operation record shown by the inspected flow; pending order after bounded polling raises an alert; ambiguous HTTP outcomes are collapsed into failure | Persist order intent/result; reconcile unknown outcome before any new purchase. Avoid retrying a non-idempotent POST as ordinary transient HTTP work |
| P0 | Plivo rate fields are labeled INR by config, while its public Number API documents USD | Account-specific contract verification is a launch gate. No automatic currency inference from region; the deployment ₹250 ceiling is not the requested US$1 policy |
| P1 | Existing billing-status helper considers Trialing, Active and PastDue “live”, gives all CanAssignNumber=true, and allows “None” as admin comp | New provider self-service gate must require actual current entitlement and approved trial/paid eligibility. Do not copy admin comp or overdue privileges into automatic spending |
| P1 | Setup success is written on the profile before line sync/ledger projection; repair branch can skip later notifications/audit | Durable completion and delivery intents; success after observed projection, with retry of every unfinished step |
| P1 | Release helper calls carrier DELETE before checking whether a non-null voiceline belongs to another business | Recheck ownership/generation and claim Returning before external release; never delete another business’s DID |
| P1 | ChangeNumberAsync throws unchanged-number before its same-number “idempotent repair” branch, making that branch unreachable for the same input | Replace implicit state-based retry with operation-ID retry, including audit/notification repair |
| P1 | Trial reminder stamps TrialReminderSentAt before NotifyAsync; a crash between them can lose that reminder | Durable delivery intent/reconciliation; do not reuse stamp-before-send as a reliable notification guarantee |
| P1 | Current trial-downgrade tail only projects allowance; pause/cancellation is not carrier release | Add explicit retention/detach/return clocks. Do not infer ownership from billing status alone |
| P1 | Cancelled voiceline is treated as unbound even though cancellation can leave a carrier number still owned | Do not seed new inventory solely by runtime Status. Confirm business lifecycle and carrier account; quarantine any ambiguity |
| P1 | Telnyx owned quote omits recurring cost; Plivo owned quote likewise returns ownership without price | Zero incremental purchase ≠ free rental; reconciliation must fetch actual owned-number cost and next charge evidence |
| P1 | Existing admin request list only includes application-submitted alerts | Add dedicated request types to both admin clients and general Alerts; do not assume a new enum automatically appears |
| P1 | ForwardExisting needs manual carrier forwarding disconnect and proof reset | Reminder/removal/reconnect UX must prevent old callers reaching a reused assistant; retain quarantine |
| P2 | Carrier search seam returns strings, discarding locality, price, compliance and capability facts | Widen the proposed search contract to structured candidates; eliminate per-candidate N+1 quotes while revalidating the selected one |

These are source-level findings. No failure was injected into shared application files, and no live carrier call was made to reproduce them.
