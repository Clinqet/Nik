## P0
- **P0-1 Furniture strip cannot see structure.** F01: later copies of `INSURANCE</figure>` are DELETED (KDP:326-341) so figures on pages 2..n never close even when page 1 is fine — moving the furniture branch below the figure branch does NOT fix it. F54: a price line as the figure close line (`Loader A⏎$23,000</figure>`) becomes furniture, figure never closes, p2 copy deleted; lost name, price, intro, marker. F13: `<figure` while open runs `figureWords.Clear()` + overwrites openFigure (KDP:595-598). Class: line-level pass blind to parser states; open state cleared not flushed. Fix: repeated-line removal on blocks / same state machine; a line inside an open figure/table/fence or carrying a tag is never a candidate; `<figure` while open → CloseFigure() first.
- **P0-2 Orphaned KeptFurniture marker eats the next structural line.** KeepFirstFurniture (KDP:226) writes marker+line; StripRepeatedPageLines deletes the line but leaves the marker; furniturePending (KDP:555-565) consumes the next non-blank line: `<table>` flattened into one glued line (F02a); `<figure>` no marker → every later picture binds wrong (F02b); `# Colour Services` stored as furniture, prices filed under the previous heading (F02c); pipe header → raw `|---|` in a card (F02d); `<!-- PageBreak -->` eaten → PageCount off by one, every later page cites one early (F60). Fix: furniture as ONE self-contained token (`<!-- KeptFurniture="…" -->`); the repeated-line pass never counts/deletes a line that is already furniture; any structural line cancels a pending state.
- **P0-3 Repetition treated as furniture; real price lines deleted.** F03 occurrences counted not pages (KDP:277-281): Kids "Haircut $25" deleted though both copies on one page. F04 same row in two sections (WAXING "Upper lips $2"). F05 identical rows on two variant pages (SUV oil change $49, wipers $25). F06 flattened list per variant: all LONG HAIR labels deleted → card "$20 $65 $80 $40", UnpairedPriceLines 0. F06b wrong price: long-hair $65 re-attaches as "Fringe | $20 | $65". F06c `$23,000` counted as printed line, Model B loses its price. F59 qualifier banner over different data on each page ("with Battery-as-a-Service" lost → subscription price reads as THE price; kept copy is furniture, never a caption KC:147). F25 GFM row without leading pipe consumed as furniture with raw pipes. Fix: count distinct pages; a running line must sit in a contiguous edge band (every line between it and the edge is running or an ordinal); a pipe row can only be a candidate as the FIRST row of a table; keep later copies as PAGE CONTEXT (rides that page's cards like a caption, no card of its own) instead of deleting; count every removal; alert when a removed line carries a price/measure. Keep green: `LayoutMarkdown_ARunningBannerSeparatedByPipes_IsStillStripped`, `LayoutMarkdown_ACountingPageNumber_IsDropped`.
- **P0-4 A short name before its price read as a bare value.** `IsValueOnlyLine` (KC:502-523, L513) accepts one word ≤4 chars in ANY position; R7 pairing (KDP:1101-1126) joins "Kids $18", "Lip $5", "Chin $4", "Neck $4" as extra columns of the line above (F41a/b/d, F19). Fix: gate R7 — a run of mostly self-contained lines (≥70% share CoalesceValueLineRuns uses) is never paired; a word is a unit only if it FOLLOWS the first digit token or no token carries its own currency/unit mark; Pptx.cs:441-442 same test.
- **P0-5 Any `<` in a paragraph flattens all its lines** (F09a/b/c vs F09z): AppendParagraphOrList (KDP:820/844) → StripInlineHtml (1406-1412) → NodeTextInline(keepLines:false) (1587) on the whole paragraph. Fix: strip inline markup per line, `<br>` = line end.
- **P0-6 A heading carrying content emits no card** (F07, F07b, F22): `### Haircut $25` headings vanish; ATX heading branch (KDP:624-636) has no price guard (R17 guard only for setext, 1371-1372); chunker never emits headings (KC:106-135). Fix: a heading whose section closes without a card is emitted as a text card in its parent; R17 guard on ATX too.
- **P0-7 Page-number shape deletes numbered section titles** (F08, F08b, F23): `## Package 1/2/3`, "Day 1/2/3", DI `PageHeader="Option 1"` after one occurrence (KDP:225). PageOrdinalLine (180-182) accepts any ≤12-letter word + number and contains English "of" (vocabulary); ordinal scan uses IsWrittenLine incl. headings. Fix: never delete a heading; delete only bare-number shapes in the edge band + DI PageNumber role. (Worded ordinals "Page 2 of 3": existing test pins dropping them.)
- **P0-8 R7 direction + wrapped-name guards defeated.** F17: price-before-name list → every price one service late, UnpairedPriceLines 0 (KDP:910 checks only lines[0]). F18: lowercase-initial line always treated as wrapped tail ("Battery replacement iPhone screen repair | $49 | $99", KDP:1220). Fix: pair both directions, refuse + count when both give the same number of pairs (≥2); a lowercase line after a row that already has its price and followed by a price starts a new record. L1 fixture stays green.
- **P0-9 Two-cell section band starts the blank-name carry** (F16b2b): `<td colspan=2>WAXING</td><td></td>` → "Service: WAXING | Price: WAXING" (an offering that does not exist). Fix: body colspan text stays in its first column only (KnowledgeBlocks.cs:64-65 contract); copy only data-shaped values; any row filled from a single source cell is a section band. Also fixes F16b (long note copied 3×; 6× live).
- **P0-10 A different table on the next page inherits the header** (F32): KDP:710-750 checks only adjacency + width. Fix: inherit only when each column's shape (text/number/price) matches.
- **P0-11 HTML table remnants dropped**: F15a text after `</table>` on the same line lost; F15b second table on the same line lost (`SelectSingleNode("//table")`, KDP:1421); F15c unclosed `<table>` swallows plain lines (6 words lost). Fix: read every top-level table in the buffer, emit text outside as paragraph; a non-markup line ends an unclosed table.
- **P0-12 Code fences**: F12 inline ```` ```Haircut $25``` ```` opens a fence, drops its text, never closes; F11 unclosed fence swallows later page breaks + rest of doc; F24 `<figure` inside a fence not counted (numbering shift); F30 furniture marker inside fence leaks. Fix: a page break always counts and closes a fence; open+close on one line = inline code, text kept.
