# Audit 3 — Page assembly + figure/picture lane, 2026-10-02

15 probes through the real compiled code (scratch deleted). Root: every writer puts a figure's closing tag on the same line as its text (CarryFigures, SectionStitcher.AddToFigure); line rules then remove/absorb that line; figure text is never compared, is published twice, and figures are placed by a one-line text search. Nothing checks assembled pages vs saved blocks; `KnowledgeFigures.MissingFrom` exists but only tests call it.

## P0
- **AS-01 Close tag shares a line with text ⇒ later pages swallowed.** PageMarkdownSplicer.cs:90 `<figure>{text}</figure>`; SectionStitcher.cs:141 AddToFigure writes `…text</figure>` (P14). (1) repeated-header strip removes `INSURANCE</figure>` (3-page probe lost $749/$995/$2,000; tags on own lines ⇒ nothing lost). (2) table inside a figure → `</table></figure>`; the table reader takes the whole line, figure never closes, the transcript's table becomes raw pipe text (P15b) — single page, no repeated header. Also multi-page TIFFs, setup, drafts re-derive. Swallowed text becomes the logo's "own words". Fix: ONE figure writer in the reader's line shape (`<figure>`, text lines, `</figure>` each alone) used by CarryFigures and AddToFigure + a shape-normalising pass in Join so pages banked in the old shape are fixed without re-reading. Tests: sweep that every assembled line containing `<figure`/`</figure>` contains nothing else; logo-on-two-pages + table-inside-figure replays; stitcher merge test. Sabotage: inline writer ⇒ 3 missing figures.
- **AS-02 A figure inserted between the rows of the transcript's table splits it** (PMS:86-91, P3): table keeps only row 1; Model Y/Z become raw pipes; "X photo | Model Y | 700 |". Fix: an insertion point inside a table block goes after the table.
- **AS-03 Figure text never checked, published twice.** (1) DocumentTranscriptUnits.Segment skips figure blocks (:54-61) ⇒ a page DI framed as one figure compares as empty ⇒ Compare returns equivalent at :53 (P8a: $20→$25, 0 discrepancies; P15c ₹9,49,000 only "added"). (2) CarryFigures carries DI figure text and CloseFigure (:496) emits it as body ⇒ logo text twice; P6 DI `₹9,99,O00` and transcript `₹9,99,000` both published. (3) LayoutFigureCaptions moves a priced caption inside its figure ⇒ comparison calls it "added" ⇒ paid check for a value both had (P9). Fix: compare figure text like any page text (skip tags); emit a figure's lines as body only where the page does not already carry them; always keep full text as the marker's own words. Changes acceptance ⇒ AdjudicationRulesVersion 1→2.

## Q6 — what "Read again" re-pays
Same build: saved blocks replayed (no re-parse); pays undescribed pictures, every card's embedding (cache in memory only), drafts pass. After any deploy (artefact mismatch): free = whole-file DI read, page readings, section readings + region machine readings, picture DI/near-duplicate/stored copies; NOT free = overview describe call (1 text call), every embedding, drafts pass, picture descriptions whose own words changed, DI analysis when a figure needs a crop and the banked result expired (~24h, :2046-2060). Parser/assembly fix ⇒ no page reading, reaches a doc only on Read again (no sweep), not sectioned pages (AS-06). Adjudication fix (1→2) ⇒ re-reads every page/section/stitched page + checks up to the ceiling. Admin reindex forceFresh re-pays everything. Recommend: always re-assemble from banks; bank the describe call keyed on blocks hash + rules version (§0.23); a free admin sweep that re-assembles every Ready doc and re-reads only those failing the check.
