## Shared conservation check (proposal)
One pure helper, no AI. Inventory per page: every amount in both readings (KnowledgePriceMarks + KnowledgeFigures.Numbers); setup also phones + times. Gate 1 after pages are joined (VDTS:501): every amount in the machine reading appears in the accepted transcript or has a review entry, else page unsettled. Gate 2 after the parse: what the consumer reads (FlattenBlocks / detector units / ingest blocks) carries every page's amounts on that page, else re-parse page alone → other reading for that page → dedicated admin alert + honest message. Gate 3 at the consumer: setup (McpService.cs:837-867) — an extracted price must be in the inventory, not a disputed amount, not from an unpaired run, else withhold (new → pending; existing → keep saved price + tell provider); drafts — a draft from a page that failed conservation is amber; a page with amounts but zero candidates sets "not fully scanned" + notice + alert. No schema change.
