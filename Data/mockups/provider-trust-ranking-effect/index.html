Provider Trust — what a score does to ranking

Each score shows its effect on ranking, the page shows the provider's total ranking factor, and while an admin types an override the page shows — before saving — exactly what it will change. Every number is calculated by the server with the one ranking formula search itself uses.

Boosts add up and stop at +27.5%. Penalties multiply and never go below ×0.50. On a typed search the boost is halved and the penalty is not. A score that is not measured yet never costs a penalty.

4 · Rules

  • One formula. Every number here comes from the server running the same ProviderBoostComposer that search runs, with the live settings — the page never computes an effect of its own, so it can never show a number ranking does not use.
  • The legend's numbers are the live settings, read from the server with the scores, never written in the page.
  • Not measured yet (fewer than the minimum samples): the tile says "Not measured yet", the effect line says "Counted as 75 for the boost · no penalty until measured" — the real rule.
  • Every box shows the measured number ("Measured: 50"); an empty box keeps it, and it keeps updating nightly. The box is never pre-filled with it — saving an untouched form would freeze today's number as an override. Not measured yet ⇒ "Not measured yet".
  • Expired override: the preview compares against the measured numbers; the expired value plays no part.
  • Permission: admin only, like the rest of Provider Trust; the preview endpoint refuses anyone else.
  • Search sync: the factor shown is what ranking uses once the provider is reindexed — the card's existing search-sync line keeps saying when that is.
