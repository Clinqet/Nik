M9 · How a cited source appears

Supersedes M2 on three points. Everything else in M2 stands — no download anywhere, the shared excerpt renderer, Show page N for genuinely paginated files, and the two panels.

The rule. A source card is a document. The parts of it the answer used are listed inside that one card, each with the number the answer cites. A document never appears twice.

Why

Measured on live CA dev, business SX3SG2, 2026-09-05. The question "What's included in a 2019 FMC/LINK-BELT 250 (M1163480)?" returned four cards — all four the same document (bd76d101d9434b75b441b54900511c56), the same title, the same subtitle "records", no page numbers, and only [1] actually quoted in the answer. That file is a scraped inventory holding 664 stored parts, one per machine, so "the document" is never what the member wanted to look at — the machine row is.

Today. Four identical cards. Nothing tells them apart, nothing says which one the answer used, and every one of them offers a Show text that fails.
M9. One card for the document, four numbered parts inside it, the cited one marked, each showing the words it contributed — and no control that cannot work.

§1 · Web — the normal case

Rules this draws

  • The count names parts, never "passages", "chunks" or "results". "The answer used 4 parts of this document."
  • A part the answer did not quote is still listed, dimmed. It was read; hiding it would overstate how narrowly the answer was grounded. The cited ones carry the brand-green number.
  • A part shows its own words immediately. No request, so it cannot fail — see §3.
  • Documents are ordered by their lowest number, so the order matches the reading order of the answer.
  • Page belongs to the document line when every part shares one, and to the part when they differ.

§2 · Web — one part only

Most answers cite one part of one document. Grouping chrome that says "1 part" is noise, so it collapses.

§3 · The control that used to fail

Measured, 2026-09-05: across the whole CA dev store there is exactly ONE saved whole-document text — and it belongs to another business. Every one of SX3SG2's three documents 404s. The document text is written by the ingest pipeline only since 2026-08-29; anything loaded before that has none, and a document over the size cap never gets one at all.

So "Show the whole document" is only ever drawn when the whole document is actually there. The words the answer used are carried with the answer itself and are always shown.

§4 · Every other state

§5 · Phone

Same rules, one column, and the parts stack. The number stays on the left so the eye can find the one the answer quoted.

‼️ CORRECTED AS BUILT, 2026-09-05. An earlier draft of this sheet said three keys retire, including TextUnavailableTitle and the server's BusinessSearch_Error_TextUnavailable. That was wrong and they are KEPT. Withholding the control removes the case where it is offered for a document that has none — it does not remove the case where the text exists at the moment the card is drawn and is gone, or unreadable, by the time the member taps. Retiring those two would have left that outcome with no words at all. A control that can still fail needs a sentence for when it does.

§7 · What this does NOT change

  • The numbering. The answer still cites one number per part, and the server still mints them. Grouping is presentation only — a [1] in the answer still resolves to exactly one part.
  • No download, anywhere. M2's rule stands.
  • Work sources (bookings, quotes, invoices, customers…) are untouched — they are one record each, so they never group. M5 §10 stands.
  • Who may see what. The per-document audience rule is unchanged and still decides whether a document is reachable at all.
  • The picture strip stays with the answer.

§8 · What it costs

  • One extra field on the wire per source — the words the answer already read. Capped at the same snippet limit the model is given, so the response grows by at most SnippetMaxChars per card.
  • Fewer requests, not more. Opening a part costs nothing; today every open is an HTTP call that usually 404s.
  • No new storage, no new index field, no new container. Nothing here engages §0.7.
