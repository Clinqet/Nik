Setup summary — what setup could not be sure of

AI Quick Setup now checks every price against the file before it goes live. When it holds a price back, keeps a price the provider already had, leaves out a line that is not a service, or could not finish reading, the "Setup complete" screen says so — in plain words, with the names. Nothing else on the screen changes. Web (provider app) and phone (provider app) show the same cards in the same order.

Status: rows approved by the owner in conversation on 2026-10-03 (PLAN-D §5, "Setup complete" rows); this sheet is drawn for the record and is registered in Data/knowledge-reading-accuracy/PLAN.md §0A.
Where the words come from: every card is the screen's own copy key, filled with the counts and names the server sends with the finished setup. The two cards marked "server sentence" mirror sentences the server already sends for knowledge files, so the wording stays the same across the product. Names in chips are the provider's own service names, exactly as saved.
Order: after the existing "needs a price", "needs a category" and "offers skipped" cards: could not finish → prices without a name → not added → kept your price → worth a look → part could not be read → long page.

4 · The other states of this screen

Loading — unchanged

While the file is read, the existing "Reading your file…" progress screen shows. The cards on this sheet appear only on the finished screen, never mid-way.

Error — unchanged

A file setup could not use at all keeps today's error screen ("Try again" / "Choose another file"). None of these cards appears on it.

Offline — unchanged

Setup cannot start offline; today's message stands. A finished summary already on screen stays as it is.

Permission denied — unchanged

A team member without the setup permission never reaches this screen (existing rule). Nothing new is shown to anyone else.

Limit reached

"Some prices weren't added" (above) is this screen's limit card: the reading's time ran out. Amber, like every limit.

Empty

No card has anything to say: none is drawn (section 2).
