Four separate faults, all visible in one screenshot. Two are layout; two are a field that is never emptied, which is a real defect and not a matter of taste.

Fault 4 is the one to notice. It is not cosmetic. After every answer the box is pre-filled with the question already answered, so pressing Ask again spends one of the day’s questions on a repeat, and the follow-up prompt is dead copy in all five languages.

The phone has the same fault, from the same line of shared code — so this sheet fixes both apps.

01 The shape — one card, one box, docked

The phone already does the right thing: the name is in the bar, the box is docked at the bottom, and its prompt changes once an answer exists. The web copies that, so the two apps share one set of rules rather than one set of component names.

The name once, in the bar. The card fills the width, edge to edge with the bar. One box, docked at the bottom and always in reach, empty, prompting for a follow-up. The answer keeps a comfortable reading width inside the card.

Why docked rather than at the top. The answer grows downwards, so a box at the top walks away from the words you are reading; a box at the bottom stays beside them. It is where the phone already puts it, where the inbox already puts its message box, and it means the box never changes places between the first question and the second.

02 Web — nothing asked yet: the suggestions and the history

Two lists sit here, and they do two different things. A suggestion, when tapped, asks — it spends one of the day’s questions. A recent question, when tapped, reopens the answer already given — it costs nothing. Today they are the same size, the same weight and the same colour, stacked under two shouting labels. That is the thing to fix.

And a suggestion is currently cut mid-word. The chips are a single line with an ellipsis, so with a real service name the provider is offered “What’s included in a Deluxe Hydra…” — a question they cannot read before spending one on it. A recent question can be up to 500 characters and is not clamped at all, so one long question becomes a paragraph in the list.

09 What this supersedes, and what it leaves alone

  • Supersedes M1 §1 on the page frame only: the page no longer prints its own name, the card fills the width, and the ask box is docked at the bottom in every state instead of sitting at the top with a second copy underneath.
  • Supersedes M4 §01b on the presentation of the suggestion row only — two lanes instead of two stacked labels, whole sentences instead of cut ones, and history clamped and capped. Every rule M4 set about which chips appear, in what order, and Opening hours being reserved stands unchanged, as does M5 §10 putting the work chips back.
  • M2 stands unchanged — source cards, their one action each, the two panels, no download anywhere.
  • M3 stands unchanged — the microphone and its eleven states, still inside the box, its message and language chips still below the box at full width.
  • M4 stands unchanged — every state it drew keeps its words and its rules; §04 above only re-frames them.
  • M5 stands unchanged — work cards, the kind labels, money quoted verbatim, the quiet line that never counts.
  • M6 is untouched — it draws a different screen.
  • Nothing on the server changes. No endpoint, no setting, no schema, no localization file.
