Why this one

  • Exactly one knowledge block on screen, in every state — never two CTAs competing.
  • The prompt is above the fold, where an unfinished-setup nudge belongs.
  • One widget: knowledge_nudge analytics event per view — the conversion rate stays readable.
  • Stops selling the moment it's done; the confirmation sits beside the settings it describes.

The cost

  • The number + usage row moves down ~74px while knowledge is empty. Mitigated by the compact one-row variant.
  • The block changes position between states, so a provider who added knowledge won't find it where it was. The bottom “Manage” link and the AI Knowledge sidebar item both still lead there.

What it buys

  • Impossible to miss — a provider who scrolls past the top still meets it at the bottom.
  • The block never moves between states.

What it costs

  • Two identical CTAs on one page reads as an ad — the classic cause of banner blindness, so it can convert worse than one well-placed prompt.
