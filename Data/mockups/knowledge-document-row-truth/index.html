F · Rules this sheet is drawn to

  • Responsive, not reflowed. Web frames hold from 1440 down to 360; the row's notice wraps under the name rather than pushing the actions off-screen. Tested shapes: laptop, iPad portrait and landscape, phone, and a folded phone at 280 pt where the pills stack and the meta line truncates from the middle.
  • Brand green fills the chosen action only. Read again in A7 and C4 are the pressed state; everything else is a quiet outline. Amber is a limit or a caution, red is a stop, blue is work in progress.
  • Nothing new is a modal. The only dialog is C4, which already exists — it gains one warning line.
  • A dismissed notice stays dismissed for that run and comes back if a later run produces a new one; it never hides a failure, only an information line.
  • Every state here is reachable from the server as it stands today. None of it is drawn for a feature that does not exist.
Deliberately not on this sheet Per-file upload refusal reasons (U-05), the picture strip's tap target (U-18), long-name truncation (U-19), the mobile MIME repair (U-12) and the copy divergences (U-22) are Phase 3 and keep their own sheet. The suggestions review screen itself is unchanged — only the empty-state sentence in C2 and the warning line in C4 are new.
