  • Not one technical word a provider can read. No conditional, DID, diversion, MMI, carrier rule, timer, forwarding condition, unconditional. The codes themselves appear only as things to copy or tap, labelled by what they do.
  • Numbers are arguments, never baked in. The ring delay is measured by the test call; the carrier and line type come from the lookup; the date is the server's.
  • The third "how it works" line is a capability. "Decline → your voicemail" is how a provider keeps junk calls off the assistant and off the bill. It is never worded as a limitation.

I · Rules this sheet is drawn to

  • An addition, never a choice. There is no "new number or my number" fork anywhere. The Clinket number stays live; connecting adds a second way in. Both work at once, safely, because in this mode we never dial the provider back.
  • One job per screen, one expander at most. Four wizard steps exist so each is trivial. Everything dense — how it works, what's not supported, disconnect — lives behind the status card's three expanders, never inside the wizard.
  • Brand green fills the chosen action only. One green button per screen. Amber is a caution or a limit, blue is work in progress, red is a stop, navy is neutral. No other colour carries meaning. Icons are lucide, the app's own set — no emoji, nothing that reads as generated.
  • The status is a date, never a light. "Last checked 15 Sep" with Check again — never a live "Active" pill. We cannot watch the carrier, so we say when we last looked. Skipping the test leaves it honestly at "Not checked yet".
  • Every failure names its own fix. Voicemail first → shorten the ring. You answered → call me again. Nothing arrived → back to the codes. Couldn't reach → check the number. Never "something went wrong".
  • The assistant never answers the test call — it couldn't be heard anyway; both ends are ours once the carrier forwards. The proof is the call arriving. "Hear it" is its own deliberate button on the status card.
  • Code 2 last, always. The second button is locked until the first is done, on web and in the app, and the amber note says why in plain words.
  • Mobile is the primary surface; web hands off. Web shows the codes and a QR to continue in the app. In the app, Android dials with one tap and iPhone copies-and-opens-Phone — iOS will not dial a code containing * or # from an app, so the sheet never pretends it can.
  • Touch has no hover. Every hover affordance on the web has a tap or long-press twin: "What changes?" is a tappable link on web and a long-press-or-tap bottom sheet in the app. Nothing is discoverable by hover alone.
  • Responsive, not reflowed. Section F is the same markup at 768 and 390 — the sidebar folds to a top bar, columns stack, the copy button wraps under the code, inputs stay 16px so iOS doesn't zoom. Tested shapes: laptop, iPad portrait, phone, and a folded phone at 280 where the code block scrolls horizontally inside its own box.
  • A locked mode is explained, never greyed. "Assistant answers every call" and "Summarize only" cannot run on the provider's own number. Each card stays visible, says in one sentence why, and — where our team can provide it — offers "Ask us to set this up", which raises an admin alert and ends in a phone call from us, never in a code the provider is left to find. The two open modes still apply in full to the Clinket number, and disconnecting restores all four.
  • The door is never one-time. The A1 card is the invitation; Assistant settings → Your numbers is the permanent address for connect, adjust and disconnect, on web and in the app.
  • The call is the proof of ownership. There is no SMS code and no OTP anywhere on this sheet — a landline could never receive one, and a forwarded call can only reach this business's number if the person who controls the line put it there. The only gate before the first dial is a plain confirm (D11 / G18): "We're about to call {number}. Is this your business phone?"
  • Confidence is earned per carrier, never per country. All three regions are switched on at launch (ruling 31), so a carrier we have measured gets the confident copy and its own ring-time cap; every other carrier — in any country — gets D9's "we haven't finished testing this with {carrier} yet — try anyway" and the default 10 seconds. Verizon and US Cellular (ruling 32) get their own step 3 with one code, no ring-time step, and both losses stated before the provider dials.
  • Never a dead end. Landline → "ask us to set it up". Unknown carrier → a picker. Region gated → "tell me when it's ready". Offline → progress kept. Permission denied → copy instead. Every edge has a next tap.
  • Every string is a key in five languages, and the two numbers on the sheet are arguments the server supplies.
