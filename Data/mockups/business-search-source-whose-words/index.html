1  The rule

A source can carry three kinds of words, and only the first kind is the provider's. The default is always the AI's own words — a source nobody has classified must never borrow a price list's authority.

2  Web — the answer and its sources

The marks sit on the source card, never in the answer text. The answer is one voice; the sources are where that voice got each part, and the reader checks a number by looking at the source it came from.

4  What the words are, and where each one comes from

Every sentence on this sheet is either a key on the screen or a sentence the server already sends, translated. Nothing is composed on the screen from parts.

On screenWeb keyPhone keyWho writes it
Described by AI from a photo businessSearch.source.aiWritten.picture BUSINESS_SEARCH.SOURCE.AI_PICTURE The screen, from the mark on the source
Summary written by AI businessSearch.source.aiWritten.overview BUSINESS_SEARCH.SOURCE.AI_OVERVIEW The screen, from the mark on the source
Not the document's own words — check the file before repeating a name, a code or a price from it. businessSearch.source.aiWritten.hint same key, shown on tap The screen
Not published existing key, unchanged The screen, from the file's own setting
Show more knowledge.drafts.showMoreUnknown DRAFTS_SHOW_MORE_UNKNOWN The screen — used only when the remainder is not known
Every failure sentence in the states above no new key The server, already translated — the screen shows it as sent

All five language files carry every new key on both apps: en-US · es-US · fr-CA · gu-IN · hi-IN on web, en · es · fr · gu · hi on the phone. The phone's counted sentences are two sibling keys (_one / _other); the web's are one string with the count inside it. Same sentence, two grammars.

✅ The one gap this sheet drew is now closed

A reopened answer used to lose its marks: each source is rebuilt field by field from what was stored, and the stored source had nowhere to keep "whose words this was" — so the same answer looked more trustworthy the second time it was read. Closed 2026-09-15 with one nullable stored field, and proven live: five marked sources identical between the live answer and the reopened one, including the photo. Absent still means the provider's own words, so a conversation stored before the change renders exactly as it did.

5  What this sheet supersedes

Nothing. It is the first sheet for the source card's truth marks. The card's layout, grouping and open behaviour stay exactly as business-search-sources and business-search-source-grouping drew them — this adds one chip row and one explanation line to a card those sheets already govern, and changes neither.
