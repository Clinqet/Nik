AI Knowledge — analytics status + picture feedback

What changes on the document row and on the pictures strip, web and mobile, every state. Same rendering rules on both surfaces. Nothing else on the page moves. Brand green = pressed/selected, navy = headings, info-blue = "in progress" (D33 chip semantics: green Ready, blue Processing/Analysing, red Failed).

1 · Analysing — Ready + a second chip, spinner while the page still checks; hover/tap explains.
2 · Found / None / Failed — unchanged outcomes; Try again / Run again hidden while Analysing.
3 · Stalled — the checks ended, the existing banner + Refresh.
4 · Picture that cannot be sent — dashed tick stays visible; hover tooltip; click/tap → notice with the reason and the remedies.
5 · Read-only member — same chip and lines, no links, no ticks.
6 · Not shared — pictures dimmed, ticks disabled (existing behaviour, unchanged).
