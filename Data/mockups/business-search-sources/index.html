How a source appears

Business Search cites the provider's own documents. This sheet shows what a team member sees for every file type we accept — and proposes that nothing is ever downloaded.

Clinqet · Business Search
Phase 2 mockup · 2026-09-02
For approval

01 The proposal

Every source is a card. Every card opens in the app. No file is ever downloaded.

Today a PDF or image opens to the exact page, because each page was read and stored as text when the document was uploaded — nothing is generated while the member waits. Word, Excel, HTML and text files never got that treatment, so they currently fall back to a download button. The proposal removes that button everywhere and gives those four types an in-app text view built from the text we already extracted at upload.

07 What this settles

No download button, anywhere

The route that handed out a file link is removed. Nothing leaves the app, so a link cannot outlive the access that produced it — which also closes the question of how long such a link should stay valid.

A page number is shown only when it is real

Word, Excel, HTML and text store a placeholder page. The server already strips it; the card shows the section or sheet name instead, and never invents a number that would send someone to nothing.

One excerpt renderer

The provider on screen and the caller on the phone read the same formatting of the same document.

Mockup for approval — no code has been written against it. Cards, panels and the phone frames use the platform's own tokens: navy ink, brand green for the chosen action.
