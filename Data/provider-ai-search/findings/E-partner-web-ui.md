## 4. Gaps / risks

1. **No markdown renderer and no typography CSS.** `react-markdown`/`remark-gfm`/`rehype-sanitize`/`marked` are absent (`package.json:26-81`); `@tailwindcss/typography` is absent (`tailwind.config.js:85`); `prose prose-sm` classes on policy pages are inert (no CSS backing). Rendering a streamed markdown/HTML answer needs a new dependency (or a hand-written renderer) plus a sanitizer path (`dompurify` exists, `package.json:48`) and bespoke CSS for headings/lists/tables/code. `react/no-danger` is a lint warning (`eslint.config.mjs:163`) and the app's baseline is 0 warnings (SKILL:1180-1181).
2. **Streaming through axios is impossible; the existing SSE client bypasses every interceptor.** `apiClient` (401 refresh, 403 access-denied bus, 409 consent) is not on the `fetch` path (`aiServices.js:148-160` only throws a response-shaped error). A search stream must handle 401 (refresh via `tokenRefreshService`) and 403 (`raiseAccessDenied(describeRefusal(...))`, `accessDeniedBus.js:51-75, 100-110`) itself, add `AbortController` (undeclared global — `eslint.config.mjs:53-82`), a stall watchdog, and cancel-on-workspace-switch (`requestGeneration()`/`contextEpoch`). Requests go **cross-origin straight to `OWNER_URL`** — `next.config.mjs` has no `rewrites()` (`:70-220`), so SSE depends on API CORS and there is no Next proxy to buffer or authenticate.
3. **`TextDecoder`/`ReadableStream` in jsdom**: tests must polyfill (`aiServices.providerSetup.test.js:13-16`).
4. **Image hosts.** Knowledge image URLs are SAS-signed blob URLs; `next/image` only accepts them with `unoptimized` (as `KnowledgeImagesPanel.jsx:195` does) or via the `remotePatterns` hosts (`next.config.mjs:8-67`). Grids must draw `thumbnailUrl` only (SKILL:14-15). A read-SAS can expire mid-session — `DerivativeImage` falls through its chain on `onError` (`DerivativeImage.jsx:17-20`).
5. **Original documents are not openable today** — the knowledge list carries no file URL and no viewer action (§2.3). A citation that deep-links to "document X, page N" needs a new read endpoint / signed URL; `DocumentPreviewModal` can host a PDF iframe but has no page-jump (`:142-147`).
6. **Permission mismatch risk for mixed citations.** Knowledge is `voice.read` (`knowledge/page.jsx:9`), services are `catalog.service.read` (`renderingRules.js:1172`); a single gate on either can leak the other's names to a role lacking it. Owner decision needed (not inferred).
7. **Route registries are numerous and build-failing**: rail (`SURFACE_PERMISSIONS` + endpoint literal verified by an API test `:1157-1160`, `Access.Surface.<x>` ×5, `ANIM_KEYS`, icon optical size, tail order), profile (`profileScreensAreCapabilityGated.test.js`), dashboard pages (`dashboardSurfacesAreGated.test.js`), header title map, `inferSurfaceFromPath`, `PAGE_SEO`, `createMetadata` layout, AASA + `linking.ts` + `types.ts` + mobile `screenMap` (partner SKILL:882-889), plus five catalogs and `sourceLocalizationIntegrity`.
8. **Header title default is the greeting** (`Header.jsx:288-289`): a new `/dashboard/<x>` without a title case renders "Welcome back, {name}" above the search page; a profile placement renders "My Profile" (`:199-204`).
9. **Mockup gate** (CLAUDE.md §0.7.1): web AND mobile, every state (empty, loading, streaming, error, permission-denied, limit-reached/rate-limited, stalled) approved before code; the knowledge mockups show the expected fidelity (`knowledge-page-layout-v5`, `knowledge-document-sharing`).
10. **Mobile parity in the same session** — provider mobile has the twin knowledge screen (`clinqetmobilepartnerapp/src/Screen/ProfileFlow/Knowledge/index.tsx`) and generated `renderingRules.ts`; a shared dependency-free rules module is the established way to keep web/mobile rendering rules identical (SKILL:1058-1074).
11. **Analytics enum**: `AIAssistantAction`, `VoiceCallAction`, `SearchAction`, `ResultClick` exist; any new EventType needs the backend `AnalyticsEventType` (clinqet-analytics skill) and mobile parity; metadata capped at 20×256 (`analyticsTracker.js:18-19`); `NavigationAction` is sampled at 25% (`:24`) — do not rely on it for funnel counts.
12. **Config hygiene**: `html-to-react` is an orphan dependency (no importer); `Loader.jsx` uses off-brand `border-blue-500`; SKILL drift — `src/app/loading.js` (SKILL:100) does not exist, `EnhancedPrivateRoute` was deleted (SKILL:182 vs 681), jest counts stale (SKILL:479, 1182).
13. **No virtualization library** — long transcripts rely on plain DOM; existing long lists use `IntersectionObserver` paging (§2.5).
14. **Only four locales are selectable** (`IntlContext.jsx:14-19`) while five catalogs must stay in parity; fr-CA needs a non-breaking space before `?` (SKILL:687).
